# River Timeline Product Brief

A product brief, not `ft possible` and not an implementation plan. Distills a transcript into domain language, then a goal.

## Product Goal

Make River a core collaborative surface. Answer: "What useful context has been shared with me?" and "Where should this document go?" Not a file tree. A living timeline with source filters and a share composer.

## Domain language

- **River** — unified timeline of shareable context
- **Source** — a person, group, or public feed you can include or exclude
- **Group** — deeper primitive than "team" (company team, friend group, repeat collaborators)
- **Contact**, **Audience**

## Call contract (sharing)

Share to public River, all contacts, one group, many groups, one person, many people; change audience later. Default destination preselected; Enter shares; modal can retarget.

## Reading model

One River per person. One timeline UI. Fast filters. An All view. Collapsible people list.

## Later work (named, not this brief)

Implementation plans sit beside this: team-river entitlement, river share destinations, river timeline picker.
