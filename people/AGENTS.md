# People

One folder per person we study.

- `person.yaml` — GitHub, X, projects, recent workflow
- `examples/` — real spec/plan specimens, not bios. Look for a **variety of kinds** (destination spec, implementation plan, ADR, eval, standing rules, HTML spec, metric loop, domain language, product brief, data model). One file per specimen. Source URL in an HTML comment at the top. Prefer different kinds over many copies of the same plan shape.

yaml: `name`, `x`, `github`, `projects`, `sites`, `workflow`, `sources`, `updated`
