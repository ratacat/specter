# Angles, then a swarm (Elvis)

The spec is the eval. Chat the plan before anything builds.

## Discovery doctrine (newsjack)

Open discovery, strict surfacing.

- Evidence-first, not model-prior-first.
- Durable search terms come from the user/profile, not "hot topics" the model remembered.
- Intake can widen. Freshness, story-origin, standing, brand-safety, and angle gates stay strict before anything is actionable.
- CLI = deterministic JSON (ingest, dedupe, scores, provenance). Skills own PR judgment, angles, prose.

Minimal memory. If it can be regenerated with one prompt, do not persist it.

## Product loop (Medialyst, 2026-08)

1. Practitioner eval (Carly list vs agent list). Anti-overfit: cannot patch her emails.
2. Same core story → several coverage *angles* (security / HR / pop-culture / finance). Chat the angle plan first.
3. One research subagent per angle, own container. Reads, picks next query from what it just found, until the thread dies.
4. Overnight data-ops swarm on the defects the eval exposed.
5. Score again. Repeat.

7-day cadence: Fri scope → weekend parallel `/goal` for 80% → Tue close 20% → Thu launch.
